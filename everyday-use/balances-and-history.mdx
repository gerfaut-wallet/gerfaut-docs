Open a wallet to read its balance, sync it and browse its transactions. The line under the page title says when the last sync ran and which server answered.

## Open a wallet

<Tabs>
  <Tab title="Desktop">
    Select the wallet switcher at the top of the sidebar, then a wallet. It opens on its Overview. Every page of the sidebar then shows that wallet.
  </Tab>
  <Tab title="Android">
    Select a wallet card on the home screen. The wallet page opens with the balance on top, then the `Transactions` and `UTXOs` tabs.
  </Tab>
</Tabs>

## Read the balance

`Total balance` already counts the transactions that are not in a block yet. An amber line under it shows the part in transit, such as `+0.00050000 BTC`. To add a fiat value under each amount, see [Units and fiat](/settings/units-and-fiat).

A note replaces the amber line when the figure is not current:

- **`Not synced yet.`:** The wallet never synced.
- **`Sync failed: nothing fetched yet.`:** The first sync failed.
- **`Sync failed: showing the last known balance.`:** A later sync failed.

## Sync a wallet

Gerfaut syncs your wallets when it opens. With [notifications](/settings/notifications) on, it also syncs a wallet as soon as a transaction touches it.

<Tabs>
  <Tab title="Desktop">
    Select **Sync all** at the bottom of the sidebar to sync every wallet of the network now.
  </Tab>
  <Tab title="Android">
    Pull the home screen down, or select the sync button in the app bar.
  </Tab>
</Tabs>

The line under the page title then reads `Synced 2 min ago · mempool.space`, or `Sync failed` with the reason.

<Note>
A sync only looks at the addresses Gerfaut already revealed. For coins received further out, select **Rescan** on the wallet in **Settings** > **Wallets**.
</Note>

<Tabs>
  <Tab title="Desktop">
    Select **Transactions** in the sidebar.

    </Frame>
  </Tab>
  <Tab title="Android">
    Select the `Transactions` tab of the wallet page.

    <Frame caption="The wallet page keeps the balance on top and the full history right under it.">
      <img src="/images/android/wallet.webp" alt="A wallet page on Android with the total balance, the Transactions and UTXOs tabs with their counts, the transaction rows and the Receive button." width="360" />

Pending transactions come first, then the others, newest first. Each row shows its status:

- **`Pending`:** The transaction is not in a block yet.
- **`1 conf` to `5 conf`:** The number of confirmations so far.
- **`Confirmed`:** Six confirmations or more.

Select a row to [open the transaction](/everyday-use/transaction-details).

## Hide every amount

<Tabs>
  <Tab title="Desktop">
    Select **Hide amounts** at the bottom of the sidebar. **Show amounts** brings them back.
  </Tab>
  <Tab title="Android">
    Select **More**, then **Hide balances**. **Show balances** brings them back.
  </Tab>
</Tabs>

Every amount becomes `•••••`: balances, transactions, the chart, notifications and the Android widgets.

## Export the history as CSV

<Steps>
  <Step title="Open the export page">
    <Tabs>
      <Tab title="Desktop">Select **Export** in the sidebar.</Tab>
      <Tab title="Android">On the wallet page, select **More**, then **Export CSV**.</Tab>
    </Tabs>
  </Step>
  <Step title="Set the filters">
    Leave `From` and `To` empty to export the full history. Under `Direction`, keep `All` or select `Received` or `Sent`. Pending transactions have no date, so `Include pending` only applies without dates.
  </Step>
  <Step title="Save the file">
    <Tabs>
      <Tab title="Desktop">Select **Export CSV…** and pick where to save the file.</Tab>
      <Tab title="Android">Select **Save file** or **Share**.</Tab>
    </Tabs>

    The file carries the wallet name, such as `cold-storage-transactions.csv`. It holds one row per transaction, oldest first, with the transaction id, date, block, confirmations, direction, amount and fee.
  </Step>
</Steps>
