Open a transaction to see how much moved, when, and between which addresses.

## Open a transaction

Select a row on the `Transactions` page or tab, or under `Latest activity` on the desktop Overview.

## Read the summary

- **Direction:** `Received`, `Sent`, `Sent to yourself` when every input and output belongs to the wallet, or `Block reward`.
- **Amount:** The net amount for the wallet.
- **Status:** `Pending`, the number of confirmations, or `Confirmed` with the block height.
- **Transaction id:** Select the chip to copy it.
- **Date:** The time of the block, or `not yet mined`.

## Follow the coins on the diagram

The diagram draws the inputs on the left, the outputs on the right and the fee below. An icon marks the role of each box:

- **Wallet:** An input spent from this wallet.
- **Return arrow:** Change that comes back to this wallet.
- **Incoming arrow:** An output this wallet receives.
- **Outgoing arrow:** An input from elsewhere, or an output that leaves.
- **Pickaxe:** Newly mined coins.
- **Scroll:** An `OP_RETURN` output that carries data.

The full `Inputs` and `Outputs` lists follow the diagram, with an address chip to copy on each line. Past ten boxes on one side, five on Android, the diagram folds the rest into one box, and the lists still show them all.

## Check the technical facts

The `Technical` card lists the confirmations, block, size, virtual size, weight, version, locktime, sigops, fee and fee rate. Its flags carry a tooltip each:

- **`RBF`:** The sender can still bump the fee. `Final` means no input signals it.
- **`SegWit` and `Taproot`:** What the inputs spend.
- **`Locktime`:** The earliest block or time the transaction could be mined in.
- **`Coinbase`:** Newly mined coins, with the mining pool when known.
- **`OP_RETURN`:** An output carries data.

Select `Raw transaction` at the bottom to show and copy the transaction bytes.

## Look it up on mempool.space

<Warning>
The operator of mempool.space can link the transaction to your IP address. Go through a VPN or Tor if that matters to you.
</Warning>

<Steps>
  <Step title="Select View on mempool.space">
    The button sits in the summary. Regtest has no public explorer, so it has no button.
  </Step>
  <Step title="Select Open explorer">
    Tick `Do not show this warning again` to skip this question next time. The transaction opens in your browser.
  </Step>
</Steps>
