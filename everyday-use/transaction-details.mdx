---
title: "Transaction details"
description: "Open a transaction in Gerfaut to read its amount, its inputs and outputs as a diagram, its fee and its technical facts, and look it up on mempool.space."
---

Every transaction opens on one page that answers the questions in the order you ask them: how much, when, from where to where, and then the technical facts.

## Open a transaction

Select a row in the transaction list, on the `Transactions` page or tab, or under `Latest activity` on the desktop Overview. On desktop the transaction opens in a modal; on Android it opens as a screen titled `Transaction`.

## Read the summary

The top panel states the direction (`Received`, `Sent`, `Sent to yourself` when every input and output belongs to the wallet, or `Block reward`), the net amount, and the fiat value under it when fiat is on. Beside it, the status pill reads `Pending`, the number of confirmations, or `Confirmed`, followed by the block height once mined.

Under the panel, the transaction id sits in a chip: select it to copy it. The date and time follow, or `not yet mined`.

## Follow the coins on the diagram

The diagram draws the inputs on the left, a `TX` node in the middle, the outputs on the right and the fee on a branch of its own below. Each box carries an icon for its role:

- **Wallet icon:** An input spent from this wallet.
- **Return arrow:** Change that comes back to this wallet.
- **Incoming arrow:** An output received by this wallet.
- **Outgoing arrow:** An input from elsewhere, or an output that leaves.
- **Pickaxe:** Newly minted coins, in a coinbase transaction.
- **Scroll:** An `OP_RETURN` output carrying data instead of coins.

Above 10 boxes on one side (five on Android), the rest fold into one box that reads `+N more inputs` or `+N more outputs`. The full `Inputs` and `Outputs` lists follow the diagram, each with its count and total, an address chip to copy, and the same role icons.

## Check the technical facts

The `Technical` card lists `Confirmations`, `Block`, `Size`, `Virtual size`, `Weight`, `Version`, `Locktime`, `Sigops`, `Fee`, `Fee rate` in sat/vB, and `Flags`. Each flag is a chip with a tooltip:

- `RBF`: the sender can still bump the fee (BIP-125). `Final` means no input signals it.
- `SegWit` and `Taproot`: what the inputs spend.
- `Locktime`: the earliest block or time the transaction could be mined in.
- `Coinbase`, with the mining pool when known, and `OP_RETURN`.

The `Raw transaction` disclosure at the bottom shows the transaction bytes, with a copy button.

## Look it up on mempool.space

Select **View on mempool.space** in the summary panel. Gerfaut first asks you to confirm, because the operator of the website can link the transaction to your IP address. Select **Open explorer** to continue, or tick `Do not show this warning again` to skip the question next time.

<Note>
Consider a VPN or Tor if that link matters to you. The button is absent on Regtest, which has no public explorer.
</Note>
