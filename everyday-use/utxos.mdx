List the coins behind a balance, one unspent output per row.

## Open the list

<Tabs>
  <Tab title="Desktop">
    Select **UTXOs** in the sidebar.

    <Frame caption="The coins behind the balance are listed one by one, with their outpoint and address.">

    </Frame>
  </Tab>
  <Tab title="Android">
    Select the `UTXOs` tab of the wallet page.

    <Frame caption="The UTXOs tab lists each coin with its outpoint, address and confirmation state.">
      <img src="/images/android/utxos.webp" alt="The UTXOs tab on Android, counting 10 coins, each with an outpoint chip, an address chip, a Confirmed pill and an amount." width="360" />
    </Frame>
  </Tab>
</Tabs>

## Read each coin

- **Outpoint:** The transaction id and the output index, as `txid:vout`. Select the chip to copy it.
- **Address:** The address that holds the coin. Select the chip to copy it.
- **Status:** `Pending` until the coin is in a block, then `Confirmed`.
- **Amount:** The value of the coin.

<Tip>
The list is read-only. Gerfaut never builds a transaction, so it has no coin selection, no freezing and no labels.
</Tip>
