---
title: "Install on Android"
description: "Download the Gerfaut APK that matches your processor, allow the install, take the welcome tour and update Gerfaut without losing your wallets."
---

Download the Gerfaut APK from the [GitHub release page](https://github.com/gerfaut-wallet/gerfaut-mobile/releases/latest) or the [download page](https://gerfaut-wallet.com/download). Gerfaut runs on Android 7.0 or newer.

<Note>
Check the APK against the signed hash list before you install it. See [Verify a download](/getting-started/verify-your-download).
</Note>

## Install Gerfaut

<Steps>
  <Step title="Download the APK for your processor">
    Take the file that matches your phone:

    | File | Processor | For |
    |---|---|---|
    | `gerfaut-v<version>-android-arm64-v8a.apk` | 64-bit ARM | Almost every phone sold since 2017. Take this one unless you know otherwise. |
    | `gerfaut-v<version>-android-armeabi-v7a.apk` | 32-bit ARM | Older or entry-level phones. |
    | `gerfaut-v<version>-android-x86_64.apk` | Intel and AMD | Emulators and Chromebooks. |
  </Step>
  <Step title="Open the downloaded file">
    The first time, Android asks you to allow your browser or files app to install unknown apps. Allow it, then open the file again.
  </Step>
  <Step title="Select Install">
    Android checks the signature of the APK, then adds Gerfaut to your launcher.
  </Step>
</Steps>

<Accordion title="Compare the signing certificate">
  Every release is signed with the same certificate. Run `apksigner verify --print-certs` on the APK, from the Android SDK build tools, and compare the SHA-256 digest of the certificate with this one:

  ```
  de91a0e0c151290a0c9b34507e58d0bd0e99cdd7db41adc65b60a7c68e0ff0a7
  ```

  <Warning>
  A different digest means a different signer, whatever the file is called. Do not install that file.
  </Warning>
</Accordion>

## Take the welcome tour

On its first launch, Gerfaut opens a welcome tour of four pages. Select **Next** to read it or **Skip** to close it.

<Frame caption="On the first launch Gerfaut states its one rule: it holds no private key and signs nothing.">
  <img src="/images/android/onboarding.webp" alt="The first-run welcome screen of Gerfaut on Android, titled Watch, never spend, with Skip and Next." width="360" />
</Frame>

The home screen then reads `No wallets yet`. Select **Add a wallet** and continue with [Add a wallet](/wallets/add-a-wallet).

<Tip>
Replay the tour from **Settings** > **About** > **Show the welcome tour**.
</Tip>

## Update Gerfaut

Gerfaut asks GitHub for the latest release at most once a day, when you open it, and tells you once about each new version.

<Warning>
The check reaches GitHub from your IP address and carries no wallet data. With a `.onion` backend, it goes [through Tor](/settings/tor) instead.
</Warning>

<Steps>
  <Step title="Select View release">
    A card such as `Gerfaut 0.2.0 is available` appears at the top of the home screen. **View release** opens the release page in your browser. **Later** hides the card until the next version.
  </Step>
  <Step title="Install the new APK">
    Download the APK for your processor and install it over the current one. Android keeps your wallets, because the same certificate signs both versions.
  </Step>
</Steps>

To check by hand, select **Check for updates** in **Settings** > **About**. To stop the daily check, turn off the `Check automatically` switch there.
