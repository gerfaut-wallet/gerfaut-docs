Gerfaut for Android is distributed as an APK on the [GitHub release page](https://github.com/gerfaut-wallet/gerfaut-mobile/releases/latest), which the [download page](https://gerfaut-wallet.com/download) also lists. It runs on Android 7.0 or newer.

<Tip>
Check the APK against the signed hash list before you install it. [Verify your download](/getting-started/verify-your-download) takes two commands.
</Tip>

## Install Gerfaut

<Steps>
  <Step title="Download the APK for your processor">
    Each release ships one APK per processor architecture. Take the one that matches your phone:

    | File | Processor | For |
    |---|---|---|
    | `gerfaut-<version>-android-arm64-v8a.apk` | 64-bit ARM | Almost every phone sold since 2017. Take this one unless you know otherwise. |
    | `gerfaut-<version>-android-armeabi-v7a.apk` | 32-bit ARM | Older or entry-level devices. |
    | `gerfaut-<version>-android-x86_64.apk` | Intel and AMD | Emulators and Chromebooks. |
  </Step>
  <Step title="Open the downloaded file">
    Open it from your browser's downloads or from your files app. The first time, Android asks you to allow that app to install unknown apps: allow it, then come back to the file.
  </Step>
  <Step title="Select Install">
    Android checks the APK signature on its own, then adds Gerfaut to your launcher.
  </Step>
</Steps>

## Take the welcome tour

On its first launch Gerfaut opens an empty vault and shows a four-page welcome tour: what it watches, how to add a wallet, which servers it talks to, and how to keep it yours. Select **Next** to read it or **Skip** to close it. You can replay it later from **Settings** > **About** > **Show the welcome tour**.

<Frame caption="Gerfaut opens on a promise: it holds no key and signs nothing.">

</Frame>

The home screen then reads `No wallets yet`. Select **Add a wallet** and continue with [Add a wallet](/wallets/add-a-wallet).

## Check the signing certificate

Every release is signed with the same certificate. If you want to compare it, run `apksigner verify --print-certs` on the APK, from the Android SDK build tools. The SHA-256 digest of the certificate is:

```
de91a0e0c151290a0c9b34507e58d0bd0e99cdd7db41adc65b60a7c68e0ff0a7
```

A different digest means a different signer, whatever the file is called. The APKs are also built reproducibly: [REPRODUCIBLE-BUILDS.md](https://github.com/gerfaut-wallet/gerfaut-mobile/blob/main/docs/REPRODUCIBLE-BUILDS.md) explains how to rebuild a release yourself and compare it with the published file.

## Update Gerfaut

Gerfaut never checks for a new version on its own. To check, open **Settings** > **About** and select **Check for updates**. When a newer release exists, a **Get** button opens its release page. Download the new APK and install it over the current one: Android keeps your data because the same certificate signs both versions.
