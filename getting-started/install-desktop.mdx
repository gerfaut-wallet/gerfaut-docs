title: "Install on desktop"
description: "Download Gerfaut for Linux, macOS or Windows, get past the warning of your system, take the welcome tour and keep Gerfaut up to date."
---

Download Gerfaut from the [GitHub release page](https://github.com/gerfaut-wallet/gerfaut-desktop/releases/latest) or the [download page](https://gerfaut-wallet.com/download). macOS warns you on the first launch and Windows when you run the installer, because Gerfaut is neither notarized by Apple nor code-signed for Windows.

<Note>
Gerfaut is in public beta and has had little testing. Check every address and amount on your signing device before you rely on it. Report anything that looks wrong on GitHub, as [Contact](/help/contact#report-a-bug-or-suggest-a-change) explains.
</Note>

## Install Gerfaut

<Note>
Check the file against the signed hash list before you open it. See [Verify a download](/getting-started/verify-your-download).
</Note>

<Tabs>
  <Tab title="Linux">
    <Steps>
      <Step title="Download the package for your distribution">
        Get one file from the release page. All three run on 64-bit Intel and AMD processors:

        - **`.deb`:** For Debian 12, Ubuntu 22.04 and newer.
        - **`.rpm`:** For Fedora.
        - **`.AppImage`:** For any other distribution with glibc 2.35 or newer, with nothing to install.
      </Step>
      <Step title="Install or run it">
        <CodeGroup>
        ```bash Debian and Ubuntu
        sudo apt install ./Gerfaut_<version>_amd64.deb
        ```

        ```bash Fedora
        sudo dnf install ./Gerfaut-<version>-1.x86_64.rpm
        ```

        ```bash AppImage
        chmod +x Gerfaut_<version>_amd64.AppImage
        ./Gerfaut_<version>_amd64.AppImage
        ```
        </CodeGroup>
      </Step>
      <Step title="Open Gerfaut">
        The `.deb` and the `.rpm` add Gerfaut to your application menu. The AppImage runs from the folder you saved it in.
      </Step>
    </Steps>
  </Tab>
  <Tab title="macOS">
    <Steps>
      <Step title="Download Gerfaut">
        Get `Gerfaut_<version>_universal.zip` from the release page, for Apple silicon and Intel Macs. Open the file to unzip `Gerfaut.app`.
      </Step>
      <Step title="Move Gerfaut to Applications">
        Drag `Gerfaut.app` into your `Applications` folder.
      </Step>
      <Step title="Open Gerfaut once">
        macOS refuses to open it. Close the warning. Since macOS Sequoia, **Open** in the right-click menu no longer gets past it.
      </Step>
      <Step title="Select Open Anyway">
        Open **System Settings** > **Privacy & Security** and scroll to `Security`. Select **Open Anyway** next to the line about Gerfaut, within an hour of the refusal.
      </Step>
      <Step title="Enter your password">
        Enter your login password and select **OK**. Gerfaut opens. From then on, macOS opens this copy without asking.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Windows">
    <Steps>
      <Step title="Download the installer">
        Get `Gerfaut_<version>_x64-setup.exe` from the release page.
      </Step>
      <Step title="Run it past SmartScreen">
        Open the file. Windows shows `Windows protected your PC`. Select **More info**, then **Run anyway**.
      </Step>
      <Step title="Complete the installer">
        Gerfaut appears in the Start menu.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Take the welcome tour

On its first launch, Gerfaut opens a welcome tour of four pages. Select **Next** to read it and **Get started** on the last page, or **Skip** to close it.

<Frame caption="The first page states that Gerfaut holds no private key and signs nothing. Skip closes the tour from any page.">

</Frame>

The page then reads `No wallets watched yet`. Select **Add a wallet** and continue with [Add a wallet](/wallets/add-a-wallet).

<Tip>
Replay the tour from **Settings** > **About** > **Show the welcome tour**.
</Tip>

## Update Gerfaut

Gerfaut asks GitHub for the latest release at most once a day while it is unlocked, starting a day after you first open it. It tells you once about each new version, and never about a pre-release.

<Warning>
The check reaches GitHub from your IP address and carries no wallet data. With a `.onion` backend, it goes [through Tor](/settings/tor#route-other-requests-through-tor) instead, and waits for Tor rather than start it.
</Warning>

<Steps>
  <Step title="Select See the update">
    A strip such as `Gerfaut 0.2.0 is available` appears above the page. **See the update** opens **Settings** > **About**. **Later** closes the strip until the next version.
  </Step>
  <Step title="Select the Get button">
    The button carries the new version, such as **Get 0.2.0**, and opens the release page.
  </Step>
  <Step title="Run the new installer">
    Download the file for your system and install it over the current one. Your wallets stay in place. macOS and Windows warn you again, as on the first install.
  </Step>
</Steps>

To check by hand, select **Check for updates** in **Settings** > **About**. A version found this way shows there, and the strip no longer announces it. To stop the daily check, turn off the `Check for updates automatically` switch there.
