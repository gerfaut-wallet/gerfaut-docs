---
title: "Install on desktop"
description: "Download Gerfaut for Windows, macOS or Linux, get past the warning on the first launch, take the welcome tour and keep Gerfaut up to date."
---

Download Gerfaut from the [GitHub release page](https://github.com/gerfaut-wallet/gerfaut-desktop/releases/latest) or the [download page](https://gerfaut-wallet.com/download). Windows and macOS warn you on the first launch, because Gerfaut is neither code-signed for Windows nor notarized by Apple.

<Note>
Check the file against the signed hash list before you open it. See [Verify a download](/getting-started/verify-your-download).
</Note>

## Install Gerfaut

<Tabs>
  <Tab title="Windows">
    <Steps>
      <Step title="Download the installer">
        Get `Gerfaut_<version>_x64-setup.exe` from the release page.
      </Step>
      <Step title="Run it past SmartScreen">
        Open the file. Windows shows `Windows protected your PC`. Select **More info**, then **Run anyway**.
      </Step>
      <Step title="Complete the installer">
        Gerfaut appears in the Start menu.
      </Step>
    </Steps>
  </Tab>
  <Tab title="macOS">
    <Steps>
      <Step title="Download Gerfaut">
        Get `Gerfaut_<version>_universal.zip` from the release page, for Apple silicon and Intel Macs. Open the file to unzip `Gerfaut.app`.
      </Step>
      <Step title="Move Gerfaut to Applications">
        Drag `Gerfaut.app` into your `Applications` folder.
      </Step>
      <Step title="Open Gerfaut once">
        macOS refuses to open it. Close the warning. Since macOS Sequoia, **Open** in the right-click menu no longer gets past it.
      </Step>
      <Step title="Select Open Anyway">
        Open **System Settings** > **Privacy & Security** and scroll to `Security`. Select **Open Anyway** next to the line about Gerfaut, within an hour of the refusal.
      </Step>
      <Step title="Enter your password">
        Enter your login password and select **OK**. Gerfaut opens. From then on, macOS opens it without asking.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Linux">
    <Steps>
      <Step title="Download the package for your distribution">
        Get one file from the release page:

        - **`.deb`:** For Debian and Ubuntu.
        - **`.rpm`:** For Fedora.
        - **`.AppImage`:** For any other distribution, with nothing to install.
      </Step>
      <Step title="Install or run it">
        <CodeGroup>
        ```bash Debian and Ubuntu
        sudo apt install ./Gerfaut_<version>_amd64.deb
        ```

        ```bash Fedora
        sudo dnf install ./Gerfaut-<version>-1.x86_64.rpm
        ```

        ```bash AppImage
        chmod +x Gerfaut_<version>_amd64.AppImage
        ./Gerfaut_<version>_amd64.AppImage
        ```
        </CodeGroup>
      </Step>
      <Step title="Open Gerfaut">
        Gerfaut appears in your application menu.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Take the welcome tour

On its first launch, Gerfaut opens a welcome tour of four pages. Select **Next** to read it or **Skip** to close it.

<Frame caption="On the first launch Gerfaut states its one rule: it holds no private key and signs nothing.">
  <img src="/images/desktop/onboarding.webp" alt="The Welcome dialog on the first launch of Gerfaut desktop, titled Watch, never spend, with Skip and Next buttons over the empty layout." />
</Frame>

The page then reads `No wallets watched yet`. Select **Add a wallet** and continue with [Add a wallet](/wallets/add-a-wallet).

<Tip>
Replay the tour from **Settings** > **About** > **Show the welcome tour**.
</Tip>

## Update Gerfaut

Gerfaut asks GitHub for the latest release at most once a day, and tells you once about each new version.

<Warning>
The check reaches GitHub from your IP address and carries no wallet data. With a `.onion` backend, it goes [through Tor](/settings/tor) instead.
</Warning>

<Steps>
  <Step title="Select See the update">
    A strip such as `Gerfaut 0.2.0 is available` appears above the page. **See the update** opens **Settings** > **About**. **Later** closes the strip until the next version.
  </Step>
  <Step title="Select the Get button">
    The button carries the new version, such as **Get 0.2.0**, and opens the release page.
  </Step>
  <Step title="Run the new installer">
    Download the file for your system and install it over the current one. Your wallets stay in place.
  </Step>
</Steps>

To check by hand, select **Check for updates** in **Settings** > **About**. To stop the daily check, turn off the `Check for updates automatically` switch there.
