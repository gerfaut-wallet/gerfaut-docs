---
title: "Install on desktop"
description: "Download the Gerfaut installer for Windows, macOS or Linux, get past the first-launch notice, take the welcome tour and update it later."
---

Download Gerfaut for desktop from the [GitHub release page](https://github.com/gerfaut-wallet/gerfaut-desktop/releases/latest), which the [download page](https://gerfaut-wallet.com/download) also lists. The builds carry no code-signing certificate, so Windows and macOS show a notice once, on the first launch.

<Note>
Check the installer against the signed hash list before you run it. [Verify a download](/getting-started/verify-your-download) takes two commands.
</Note>

## Install Gerfaut

<Tabs>
  <Tab title="Windows">
    <Steps>
      <Step title="Download the installer">
        Get the `-setup.exe` file from the release page, or the `.msi` package if you prefer one.
      </Step>
      <Step title="Open it and pass the SmartScreen notice">
        Windows shows a SmartScreen notice because the installer is not signed. Select **More info**, then **Run anyway**.
      </Step>
      <Step title="Complete the installer">
        Gerfaut appears in the Start menu once the installer finishes.
      </Step>
    </Steps>
  </Tab>
  <Tab title="macOS">
    <Steps>
      <Step title="Download the disk image">
        Get the `.dmg` file from the release page and open it.
      </Step>
      <Step title="Drag Gerfaut to your Applications folder">
        Then eject the disk image.
      </Step>
      <Step title="Open Gerfaut once and let macOS refuse it">
        macOS refuses an app that is not notarized. Close the notice.
      </Step>
      <Step title="Allow it in System Settings">
        Open **System Settings** > **Privacy & Security** and select **Open Anyway**, the button that appears there after the refusal. Open Gerfaut again: macOS asks once more, then opens it every time.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Linux">
    <Steps>
      <Step title="Download the package for your distribution">
        Get one file from the release page:

        - **AppImage:** A portable build that runs on any distribution.
        - **`.deb`:** For Debian and Ubuntu.
        - **`.rpm`:** For Fedora.
      </Step>
      <Step title="Install or run it">
        <CodeGroup>
        ```bash AppImage
        chmod +x <file>.AppImage
        ./<file>.AppImage
        ```

        ```bash Debian and Ubuntu
        sudo apt install ./<file>.deb
        ```

        ```bash Fedora
        sudo dnf install ./<file>.rpm
        ```
        </CodeGroup>
      </Step>
      <Step title="Open Gerfaut">
        Gerfaut appears in your application menu.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Take the welcome tour

On its first launch Gerfaut opens an empty vault and a four-page welcome tour: what it watches, how to add a wallet, which servers it talks to, and how to keep it yours. Select **Next** to read it or **Skip** to close it.

<Frame caption="On first launch Gerfaut states its one rule: it holds no key and signs nothing.">
  <img src="/images/desktop/onboarding.webp" alt="The Welcome dialog on the first launch of Gerfaut desktop, titled Watch, never spend, with Skip and Next buttons over the empty layout." />
</Frame>

The canvas then reads `No wallets watched yet`. Select **Add a wallet** and continue with [Add a wallet](/wallets/add-a-wallet).

<Tip>
Replay the tour any time from **Settings** > **About** > **Show the welcome tour**.
</Tip>

## Update Gerfaut

Gerfaut never checks for a new version on its own.

<Steps>
  <Step title="Open Settings > About">
    Select **Check for updates**.
  </Step>
  <Step title="Select Get">
    The button appears when a newer release exists and opens its release page.
  </Step>
  <Step title="Run the new installer">
    Download the installer for your system and run it over the current one. Your wallets stay in place.
  </Step>
</Steps>
