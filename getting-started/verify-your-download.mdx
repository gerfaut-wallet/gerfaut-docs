---
title: "Verify a download"
description: "Prove in two commands that a Gerfaut installer or APK is the file the author published, with the signed hash list that ships with every release."
---

Every Gerfaut release carries a `SHA256SUMS` file listing the hash of each installer and APK, and a `SHA256SUMS.minisig` signature made with the author's [minisign](https://jedisct1.github.io/minisign/) key. One command proves that the list comes from the author, a second one proves that your file matches it.

The author's minisign public key is:

```
RWTz3c4gUmglCX5Uvjthigz1ts3TS3ZSdhRNpFgOJRW/Wr4XjGlqTR3O
```

## Verify a file

<Steps>
  <Step title="Install minisign">
    Get it from the [minisign page](https://jedisct1.github.io/minisign/) or from your package manager.
  </Step>
  <Step title="Download the hash list and its signature">
    Take `SHA256SUMS` and `SHA256SUMS.minisig` from the same release page as your file, and put all three in one folder.
  </Step>
  <Step title="Check the signature of the hash list">
    From that folder, run:

    ```bash
    minisign -Vm SHA256SUMS -P RWTz3c4gUmglCX5Uvjthigz1ts3TS3ZSdhRNpFgOJRW/Wr4XjGlqTR3O
    ```

    minisign prints `Signature and comment signature verified` when the list comes from the author.

    <Warning>
    Any other answer means the list was altered or signed by someone else. Do not use the file.
    </Warning>
  </Step>
  <Step title="Check that your file matches the list">
    <Tabs>
      <Tab title="Windows">
        In PowerShell, compute the hash of your file and find its line in the list:

        ```powershell
        (Get-FileHash .\<file>).Hash
        Select-String <file> SHA256SUMS
        ```

        The two hashes must be identical, letter for letter.
      </Tab>
      <Tab title="macOS">
        ```bash
        shasum -a 256 --check SHA256SUMS --ignore-missing
        ```

        The command prints `OK` after the name of your file.
      </Tab>
      <Tab title="Linux">
        ```bash
        sha256sum --check SHA256SUMS --ignore-missing
        ```

        The command prints `OK` after the name of your file.
      </Tab>
    </Tabs>
  </Step>
</Steps>

## Compare the Android certificate

Android checks the APK signature on its own when it installs the file. To compare the signing certificate with the one every release uses, or to rebuild a release from source, open **Compare the signing certificate** in [Install on Android](/getting-started/install-android#install-gerfaut).
