Gerfaut is written and maintained by Loïc Morel. Pick the channel that fits what you have to say.

## Ask a question

Write to [info@pandul.fr](mailto:info@pandul.fr), in English or in French.

## Report a bug or suggest a change

Open an issue in English on the repository concerned:

- **Android:** [gerfaut-wallet/gerfaut-mobile](https://github.com/gerfaut-wallet/gerfaut-mobile/issues).
- **Linux, macOS and Windows:** [gerfaut-wallet/gerfaut-desktop](https://github.com/gerfaut-wallet/gerfaut-desktop/issues).
- **These pages:** [gerfaut-wallet/gerfaut-docs](https://github.com/gerfaut-wallet/gerfaut-docs/issues).

## Report a security vulnerability

<Note>
Never report a vulnerability in a public issue. The `SECURITY.md` file of each code repository, such as [gerfaut-desktop](https://github.com/gerfaut-wallet/gerfaut-desktop/blob/main/SECURITY.md), sets out the scope and the disclosure terms.
</Note>

Report it privately on GitHub, or by e-mail to [info@pandul.fr](mailto:info@pandul.fr) if you have no GitHub account.

<Steps>
  <Step title="Open a private report on GitHub">
    On the repository concerned, select **Security**, then **Report a vulnerability**. Only you and the maintainer see the report.

    - **Android:** [gerfaut-wallet/gerfaut-mobile](https://github.com/gerfaut-wallet/gerfaut-mobile/security/advisories/new).
    - **Linux, macOS and Windows:** [gerfaut-wallet/gerfaut-desktop](https://github.com/gerfaut-wallet/gerfaut-desktop/security/advisories/new).
    - **Code shared by both apps:** [gerfaut-wallet/gerfaut-core](https://github.com/gerfaut-wallet/gerfaut-core/security/advisories/new).
    - **Website:** [gerfaut-wallet/gerfaut-web](https://github.com/gerfaut-wallet/gerfaut-web/security/advisories/new).
    - **These pages:** [gerfaut-wallet/gerfaut-docs](https://github.com/gerfaut-wallet/gerfaut-docs/security/advisories/new).
  </Step>
  <Step title="Describe what you found">
    Include what you can:

    - **Type:** The kind of issue and the component affected.
    - **Reproduction:** Steps to reproduce, or a proof of concept.
    - **Impact:** How you assess it.
    - **Fix:** Any fix you suggest.
  </Step>
  <Step title="Wait for the acknowledgement">
    You get an acknowledgement within seven days, then a verdict and news while a fix is under way.
  </Step>
</Steps>
