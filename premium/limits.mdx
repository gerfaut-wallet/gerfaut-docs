Check the ceilings of your Premium licence key before a habit or a large wallet meets one. Gerfaut shows each refusal under the card concerned, in the Premium server's own words, with **Retry** when trying again can work.

## Check the ceilings of a licence key

| Ceiling | Limit | Past the limit |
|---|---|---|
| Wallets watched | 21 per licence key | The server refuses a new wallet with `a key watches at most 21 wallets; remove one first`. |
| Coins in one watched wallet | 5,000 | The server stops watching the wallet and says why, as below. |
| Wallets switched on or changed | 30 an hour per licence key | Gerfaut says `Try again in` with the wait, such as `Try again in 42 s.` Renaming a wallet does not count. |
| Channels | 10 per licence key | The server refuses an eleventh channel, and a duplicate with `this channel already exists`. |
| Requests | 60 a minute per licence key, 240 a minute per IP address | Gerfaut says `Try again in` with the wait. |

## Watch a wallet with more than 5,000 coins again

When the first scan or a later payment takes a wallet past 5,000 coins, the server stops watching it. Your own [notifications](/settings/notifications) still cover it. Gerfaut shows this sentence under the wallet's row in `Watched wallets`, in `Recent alerts` and on your channels:

`This wallet holds more than 5,000 coins, which is more than Gerfaut Premium watches.`

<Steps>
  <Step title="Bring the coins together">
    With your signing device or wallet software, consolidate the wallet's coins into fewer outputs.
  </Step>
  <Step title="Switch the wallet off, then on again">
    In **Settings** > **Premium**, select the switch of the wallet, then **Unwatch**. Switch it on again. The server scans the wallet anew.
  </Step>
</Steps>

## Check the message ceilings

| Ceiling | Limit | Past the limit |
|---|---|---|
| Tests and confirmation e-mails | Five an hour per licence key | The server refuses them until the hour has passed. |
| E-mail alerts | 20 a day per licence key | E-mail alerts wait for the next day. The other channels are untouched. |
| E-mail confirmation code | One hour, five wrong tries | Add the channel again for a new code. |
| Telegram link code | One hour | Add the channel again for a new code. |

## Know what stops after the paid time

- **Alerts:** They continue for seven days after the paid time ends, then stop until you add time.
- **Daily scans and timelock alerts:** They stop at the same point.
- **Watched wallets:** Switching a wallet on or off needs paid time left.
- **Your data:** The server deletes it after a while. See [Delete your data](/premium/delete-your-data#let-the-server-delete-on-its-own).
