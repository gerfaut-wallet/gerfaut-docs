description: "Save every wallet you watch in an encrypted Gerfaut backup file or an animated QR code, and restore it on another computer or phone."
---

Seal every wallet you watch in a backup under a password of your own, as a file or an animated QR code, and restore it on another computer or phone. A backup holds descriptors, addresses and names, never a private key or a seed.

Open **Settings** > **Backup & sync**.

## Export a backup

<Warning>
Nobody can recover the password. Someone who copies the file can try passwords offline, so pick a long passphrase of several words.
</Warning>

<Steps>
  <Step title="Select Export…">
    Gerfaut opens `Export a backup`.
  </Step>
  <Step title="Pick what goes in">
    Keep `All wallets (5)`, or take only the wallets of the selected network with an option such as `Signet only (3)`. Gerfaut offers that choice when you watch wallets on more than one network. Select the `Include node settings` switch to add your backend, the certificates you accepted and the gap limit.
  </Step>
  <Step title="Pick a password">
    Enter it in `Password` and `Confirm password`, then select **Create backup**.
  </Step>
  <Step title="Save the file or show the QR code">
    Select **Save file…** to write a `.gerfaut` file, or **Save file** and **Share** on Android. Select **Show QR code** to show the backup as an animated QR code.
  </Step>
</Steps>

## Restore a backup

<Steps>
  <Step title="Select Restore…">
    Gerfaut opens `Restore a backup`.
  </Step>
  <Step title="Open the backup">
    Select **Open a file…** (**Open a file** on Android) and pick the `.gerfaut` file, or **Scan a QR code** and keep the camera on the code until the counter reaches its total. One loop of the code is enough.
  </Step>
  <Step title="Enter the password">
    Select **Open backup**. A wrong password reads `Wrong password, or the file is damaged.`
  </Step>
  <Step title="Pick what to restore">
    Gerfaut ticks every wallet this device does not watch yet, and marks the others `Already watched`. If the backup holds node settings, select the `Apply node settings` switch to take its backends, accepted certificates and gap limit.
  </Step>
  <Step title="Select the Restore button">
    It counts the wallets, such as **Restore 2 wallets**. Gerfaut adds the wallets and syncs them.
  </Step>
</Steps>

<Note>
On Android, the encryption key of the vault never leaves the phone, so a system backup of the phone does not bring your wallets back. Keep a Gerfaut backup for a new phone.
</Note>
