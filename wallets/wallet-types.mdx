Check what Gerfaut makes of what you paste, open or scan, and what to confirm before you add it.

## Give Gerfaut one of these inputs

| Input | Recognized as | What Gerfaut watches |
|---|---|---|
| An output descriptor (`wpkh`, `sh`, `wsh`, `tr`, `multi`, `sortedmulti`) | `Output descriptor` | The receive branch, and the change branch when the descriptor names it. |
| A multipath descriptor with `<0;1>` | `Multipath descriptor (BIP-389)` | Both branches. |
| Two descriptors on two lines | `Descriptor pair (receive + change)` | Both branches. |
| An extended public key (`xpub`, `tpub`, or a SLIP-132 `ypub`, `zpub`, `upub`, `vpub`) | `Extended public key` | The `0/*` and `1/*` branches under that extended public key. |
| A single address | `Single address` | That address only. See [Watch an address](/wallets/watch-an-address). |
| The export file of another wallet | `Wallet export file` | The descriptor the file holds. When it holds several account types, Gerfaut picks the preferred one and says so. |
| A BSMS record (BIP-129) | `BSMS record` | The multisig descriptor in the record. Gerfaut refuses the file if its first address differs from the one the record promises. |

A multisig wallet arrives as a descriptor, pasted, scanned or read from a BSMS record. A descriptor with a Miniscript policy and timelocks also gets a [Policy page](/wallets/policy-and-timelocks).

## Pick the script type of an extended public key

A bare `xpub` does not name its script type. Gerfaut reads it from the SLIP-132 prefix (`ypub` for Nested SegWit, `zpub` for Native SegWit), then from a key origin such as `[fingerprint/84'/0'/0']`, and falls back to Native SegWit.

- **SLIP-132 prefix:** The card reads `The SLIP-132 prefix was converted to a standard extended key.` The same conversion applies inside a descriptor.
- **No script type:** The card reads `This key carries no script type. Check the one selected below.` Select the type your wallet software uses.

| Script type | Addresses start with |
|---|---|
| `Legacy (P2PKH)` | `1` |
| `Nested SegWit (P2SH-P2WPKH)` | `3` |
| `Native SegWit (P2WPKH)` | `bc1q` |
| `Taproot (P2TR)` | `bc1p` |

<Warning>
Each script type gives other addresses. Compare the new `First address` with the one your signing device or wallet software shows before you select **Add wallet**.
</Warning>

## Pick a network

Gerfaut watches wallets on `Mainnet`, `Signet`, `Testnet 4` and `Regtest`. A `tpub` or a `tb1` address only fits the test networks. Gerfaut only shows the wallets of the network selected in **Settings** > **Network**.

## Read a refusal

Each refusal names the input and says where it belongs:

- **Private key material:** Gerfaut refuses an `xprv`, a WIF key or a seed phrase, and never stores it.
- **Multisig cosigner key:** A `Ypub`, `Zpub`, `Upub` or `Vpub` key belongs to a multisig. Import the full multisig descriptor instead.
- **Signed transaction or PSBT:** Send it from [Broadcast](/everyday-use/broadcast-a-transaction).
- **Gerfaut backup:** Restore it from [Backup and sync](/settings/backup-and-sync).
- **One part of an animated QR code pasted as text:** Scan the code with the camera.
